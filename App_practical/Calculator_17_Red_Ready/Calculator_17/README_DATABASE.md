# Calculator_17 — MariaDB и история вычислений

## Что добавлено
- MariaDB 11.4 в отдельном Docker-сервисе `mariadb`.
- Таблица `CalculationHistories`, создаваемая приложением при первом старте.
- Сохранение успешных вычислений и раскрывающаяся история последних 50 операций.
- Веб-приложение слушает порт 5518.
- База не публикует порт 3306 наружу.

## Локальный запуск через Docker Compose
1. Скопируйте `.env.example` в `.env`.
2. В `.env` задайте собственные сложные пароли для `MARIADB_ROOT_PASSWORD` и `MARIADB_PASSWORD`.
3. Выполните `docker compose up -d --build`.
4. Откройте http://localhost:5518.

Данные MariaDB сохраняются в Docker volume `calculator17_db_data`. Не удаляйте его командой `docker compose down -v`, если хотите сохранить историю.

## HeidiSQL
Для безопасного доступа к БД на сервере используйте SSH-туннель: локальный порт 3307 перенаправьте на серверный адрес контейнера/БД порт 3306. Не публикуйте 3306 в интернет. В HeidiSQL подключайтесь к `127.0.0.1:3307`, пользователь `calculator_user`, база `calculator17`, пароль из `.env`.

## Важно
`appsettings.json` содержит пример строки подключения для локального запуска. Docker Compose переопределяет её адресом `mariadb`. Не храните реальные пароли в Git.
